# 二维雷达显示平台 · 用户使用手册

> 面向：**值班员 / 预报员 / 业务使用者**（不需要懂代码）。
> 开发人员请看 `docs/PRODUCT_GUIDE.md`（产品与色标开发）与 `docs/DEPLOY_GUIDE.md`（部署运维）。
> 版本 v1.0｜2026-10-26｜本手册的按钮名称、默认状态、提示文案均按当前界面实测编写。

---

## 1. 这个平台能做什么

在一张地图上，把雷达数据（反射率、径向速度、谱宽等）画成分级色斑图，并且可以：

- **看时间演变**：底部时间轴拖动 / 点击 / 自动播放动画；
- **多产品对比**：同屏最多 6 个画面并排，各自显示不同产品或不同时刻；
- **任意点取值**：点击地图直接读出该点数值，或输入经纬度精确查询；
- **换仰角层**：单站基数据可切换 9 个仰角层（0.5°～19.5°）看不同高度的回波；
- **裁强度区间**：在色标上拖两个手柄，只让某个强度区间上图；
- **看本地文件**：把雷达文件拖进平台直接渲染（不上传服务器）。

**你需要知道的唯一前提**：用浏览器打开平台地址即可（形如 `http://<服务器地址>:9094/`，具体地址问管理员），需要较新的 Chrome / Edge 浏览器，无需安装任何插件。

**「激活屏」概念**：界面上带 `●` 圆点、边框高亮的那一屏就是激活屏。产品列表的选择、时间轴的拖动、播放的推进，**都只作用于激活屏**（除非开了「多屏同步」）。点任意一屏即可把它设为激活屏。

初始默认状态：单屏 · 国界底图 · 产品「反射率（dBZ）」· 不平滑 · 全色标范围 · 多屏同步开 · 地图联动开。

## 3. 五分钟上手

1. 打开地址，等画面左下/中部出现地理轮廓（首次进「国界」底图需加载约 4MB 边界数据，稍慢属正常）。
2. 左侧产品列表点一个产品（默认是**反射率（dBZ）**）。
3. 底部时间轴：按住刻度轴左右拖动，**松手会自动吸附到最近的一个时次**并加载该时刻数据；也可以直接点刻度轴上某一刻。
4. 回波上色后，**点击地图上任意位置**，弹窗显示该点数值与经纬度。
5. 想看成片回波怎么移动：点工具栏 `▶ 播放`（每 0.8 秒推进一个时次，放完自动从头循环），再点 `⏸ 暂停` 停下。

## 4. 各区域怎么用

### 4.1 顶部工具栏

| 控件 | 作用 | 说明 |
|---|---|---|
| `1屏 / 2屏 / 4屏 / 6屏` | 切换同屏画面数量 | 用于对比。**多屏同步开着时**：各屏同一时刻、不同产品；**关掉后**：各屏时间独立，可对比不同时刻 |
| 底图 `行政` | 天地图矢量 + 中文注记 | 需要你的电脑能访问瓦片服务（内网节点或外网）。打不开就是一片空白底图 |
| 底图 `国界`（默认） | 陆地/海洋填色 + 国界/省界线 | **完全不依赖外部服务**，内网、断外网也能用；首次加载约 4MB |
| ☑ `多屏同步` | 时间轴控制所有屏 | 关掉后每屏时间独立，方便看「同一产品不同时刻」 |
| ☑ `地图联动` | 任一屏缩放/平移，其余屏跟着同样视野 | 关掉后各屏可独立看不同区域 |
| `▶ 播放 / ⏸ 暂停` | 时间动画 | 0.8 秒一档，到最后一档自动回头；某屏还在加载时会**暂停推进**（不堆请求） |

### 4.2 左侧产品列表

面板标题下写着「作用于第 N 屏」，点某产品即改变激活屏的产品。8 个内置产品：

| 名称 | 代码 | 单位 | 看什么 |
|---|---|---|---|
| 反射率（dBZ） | `dBZ` | dBZ | 降水强度和位置（**最常用**，滤波后反射率） |
| 原始反射率（dBT） | `dBT` | dBZ | 未做地物/噪声抑制的反射率，杂波对比用 |
| 径向速度（V） | `V` | m/s | 朝向/远离雷达的运动分量，看气旋、辐合 |
| 谱宽（W） | `W` | m/s | 同一分辨单元内速度散布，湍流/风切变 |
| 差分反射率（ZDR） | `ZDR` | dB | 粒子形状，大水滴/冰雹判别 |
| 相关系数（CC） | `CC` | — | 粒子一致性，非气象物（虫/沙）识别 |
| 差分相移率（KDP） | `KDP` | °/km | 强降水率指示，大雨核位置 |
| 信噪比（SNRH） | `SNRH` | dB | 数据质量，低值区的回波不可信 |

每项右侧有「实况 / 预报」类型标签。名称里已括注单位的，右边就不再重复显示单位。

> **注意**：径向速度、谱宽等多普勒量**只在近距离圈有采集**。基数据的 V/W 通常只有 230km 范围内有值，远处空白是**数据本身如此**，不是平台坏了。

### 4.3 屏头（每一屏自己的控制）

| 元素 | 说明 |
|---|---|
| `第 N 屏` | 屏序号 |
| `产品 · MM-DD HH:mm` | 本屏当前显示的产品与时刻 |
| **状态文字** | 见 §6 状态对照表（`加载中…` / `该时次无数据` / `上传失败原因` 等） |
| `⚠ 示意数据` | **红色标记**，与状态文字分开显示；出现即代表画面不是实际天气，禁止业务判断 |
| `●` | 本屏是激活屏 |
| **仰角下拉**（`0.5°  1.5° … 19.5°`） | **只有单站基数据文件才会出现**。一个文件含 9 个仰角层，切换即重新读取该层（不重新下载文件）。拼图、m4 等没有这个下拉 |
| ☑ `平滑` | 勾上＝双线性插值（色带过渡柔和）；不勾＝**格点填色**（原始方块，默认）。两种模式的分级色标完全一致 |
| `上传` | 选择本机雷达文件在**本屏**渲染。支持 `.bin`（CINRAD 基数据 / SWAN 拼图）、`.m4`（MICAPS 第 4 类文本），以及它们的压缩包 `.bin.bz2` / `.m4.bz2`（**浏览器内解压，无需先手工解压**）；单文件上限 **200MB** |

上传后的行为：屏状态显示「上传数据 · 文件名」，地图自动定位到该文件范围；这只是**本屏当前视图**，你一切换时次，就恢复成时间轴上的正式数据。若该文件**没能真实解码**，屏头会额外出现红色「⚠ 示意数据」标记（见 §6），此时画面不是实际天气。

### 4.4 色标图例（右下角，可拖动）

- **按住图例任意空白处即可拖动**，在本屏地图范围内随意摆放；切换布局或缩放窗口后会自动被"夹"回可见区域（不会丢失）。
- 色标条上有**两个圆点手柄**：左=下限、右=上限，选中区间 `[min, max)` 内的颜色才会画到地图上，**区间外的回波变成透明**，图例上对应色块同时变暗作提示。
  - 手柄是**按档拖动**的：一次移动一整档颜色，不会出现"半档"状态。
  - 图例下方文字显示当前区间，如 `20 ~ 55 dBZ`；全范围时显示「全范围」。
  - 出现「重置」按钮时点它即可恢复全范围。
  - 范围设置是**每屏独立**的：A 屏裁了 20~55，B 屏不受影响。
- 色标数字是**每档下限**：某格点数值落入 `[本档值, 下一档值)` 就显示本档颜色。

### 4.5 坐标查询（左下角）

1. 分别填「经度」（如 `118.9269`，范围 -180~180）和「纬度」（如 `33.6378`，范围 -90~90）；
2. 点「查询」或在任一框按**回车**；
3. 结果三行：
   - `原始：X.X 单位` —— 该点**最近邻库**的真实值（保峰值，与图上颜色同口径）；
   - `9 点均值：X.X 单位（n/9 有效）` —— 周围 3×3 邻域平均（抑噪，会**压低强中心**）；有效库不足 5 个时不给均值，显示 `—`；
   - 橙色说明行 —— 为什么图上可能是透明的：`低于显示阈值 5dBZ（图上透明）` 或 `超出当前色标范围（图上透明）`；
4. 「来源：…」一行 —— 标明本次数值是**怎么取来的**（不同文件后缀口径不同，见 Q11）：
   - `MICAPS m4 格点（最近邻取值）`、`SWAN 拼图格点（最近邻取值）` —— 格点产品，按最近格点取值，**没有 9 点均值**；
   - `RSTM 基数据 0.5°（原始径向）` —— 单站单仰角原始基数据，按原始径向库取值，换仰角即换高度；
   - `RSTM 合成兜底（示意数据，非实测）` —— 文件没能真实解码，数值不可用。
   鼠标悬停该行可看完整解释；
5. 最下面一行回显查询坐标 `纬度°N/S, 经度°E/W`（4 位小数；负值显示为南纬 / 西经，不会出现 `-100°E` 这种写法）。

容错：把 `118.9269,33.6378` 整串粘进经度框（纬度框留空）会自动拆开。真·无数据时「原始」行显示 `无数据`，说明行给出 `无数据（超出数据范围或缺测）` —— 结果全在面板里，**不再额外弹提示**。

面板底部固定有一行可展开的 `不同文件结果为何不同？`，点开就是差异原因说明（默认收起，不占地方）。

> **直接点地图**也能取值（弹窗内容同上），且点地图是"静默"的：没有数据时只收起弹窗，不弹提示。

### 4.6 底部时间轴

| 控件 | 操作 | 结果 |
|---|---|---|
| `◀` `▶` | 点一下 | 上一个 / 下一个**时次**（到头就停，不会越界） |
| **刻度轴** | 按住左右拖 | 时间窗平移，**拖动过程中不加载数据**，松手才吸附到最近时次并加载 |
| | 直接点某刻度 | 跳到该时次 |
| | 滚轮 | 缩放时间窗（看密集时次或看长时间跨度） |
| | 顶部**绿色小刻度** | 表示该时次**有数据文件** |
| 时间跳转框（右侧日期控件） | 选到 `YYYY-MM-DD HH:mm` | **按所选分钟时刻直接找文件，不做吸附** → 若该分钟没有对应文件，屏上显示「该时次无数据」。**建议优先用刻度轴拖拽**，它会自动吸附到最近可用时次 |
| `起报时间 / 结束时间` 控件（仅在有服务器配置时出现） | 选一个时间 | 以该时刻为锚点**重新生成整条时间轴**（实况模式=结束时间往前推，预报模式=起报时间往后推），并跳到该时次 |
| 右侧文字 | — | 当前时刻 + `第 N / M 时次`；一个时次都没有时显示橙色 `无可用时次`（悬停看原因） |

> **关于"最新数据"**：时间轴的可用范围是在你**打开页面的那一刻**确定的。页面挂久了要 newer 时次，请在时间轴上**重新选一次锚点时间**，或者直接**刷新页面**（推荐 Ctrl+F5）。

## 5. 怎么读这张图

- **颜色=强度档位**，具体数值看右下角图例的刻度（每档下限）。
- **透明（没上色）有三种原因**，务必区分：
  1. **低于该产品的显示阈值**（反射率默认 5 dBZ）——弱回波/噪声被挡掉，但**坐标查询仍能查到原始值**；
  2. **被你选的色标范围裁掉**——图例上那段色块是暗的；
  3. **超出数据覆盖范围或该库缺测**——查询会明确回答「无数据（超出数据范围或缺测）」。
- **单站基数据是扇形/圆形覆盖**，边缘有放射状空白是扫描与质控的自然结果。
- **换仰角层看的是不同高度**：仰角越高，波束离地越高。远距离处低仰角波束可能已经"越过"浅层降水云，表现为**高仰角反而无回波**；反之台风/强对流的中高层结构要看高仰角。
- **径向速度的颜色不是随便跳的**：它正负代表远离/靠近雷达，超出探测上限（Nyquist）会出现折叠（相邻颜色突变，形成"棋盘"或"速度绕圈断裂"）。近距离多普勒速度梯度极大，换 1 公里颜色跳档是正常现象。
- **放大地图后色块变大方块**：这是「格点填色」模式，显示的是原始数据分辨率，不是图像模糊。想要柔和效果就勾屏头的「平滑」。

## 6. 屏头状态对照表（看到什么 → 是什么意思 → 该怎么办）

> **颜色也能读**：状态文字按语气配色——**蓝色**=正在进行（`加载中…`/`识别中…`）、**灰色**=数据来源说明（`上传数据 · 文件名`）、**橙色**=需要注意（无数据等）、**红色**=失败（`加载失败`、上传被拒）。
> 红色「⚠ 示意数据」是**独立标记**，可与状态文字同时出现；一旦出现，画面不是实际天气，禁止用于业务判断。

| 状态文字 | 含义 | 你该怎么做 |
|---|---|---|
| （空白） | 正常显示正式数据 | — |
| `加载中…` | 正在下载/解析该时次文件（单文件可达 7~35MB） | 稍等；长时间不动看下一条 |
| `该时次无数据` | 这个时刻**没有对应文件**。清单模式下会带上「（最近可用 MM-DD HH:mm:ss）」 | 用刻度轴拖到该时刻或最近的**绿色刻度**；或确认数据是否已生产/落盘 |
| `加载失败` | 请求出错：网络不可达、服务未启动、**或 10 秒内无响应（超时）** | 刷新页面；仍失败联系管理员（部署问题见 `DEPLOY_GUIDE.md`） |
| `⚠ 示意数据` | ⚠ **红色标记**（独立于状态文字）：该文件没能真实解码，画面是程序生成的**演示团块，不是实际天气** | **不要用它做任何判断**，换时次或联系管理员核查数据文件 |
| `识别中…` | 正在识别你上传的文件 | 稍等 |
| `上传数据 · 文件名` | 本屏显示的是你刚上传的本地文件 | 切时次即恢复正式数据 |
| `仅上传模式：点屏头「上传」加载文件` | 服务器配置为「只用上传文件」，切换时次后画面为空是预期行为 | 点屏头 `上传` 选文件 |
| `文件格式不符` | 上传的不是受支持格式 | 只支持 `.bin` / `.m4`（含 `.bz2` 压缩包）；确认没选错文件 |
| `文件过大` | 上传文件超过 200MB 上限 | 换更小的文件，或先在本地解压/裁剪 |
| `文件损坏` | `.bz2` 解压失败（文件被截断或本身已损坏） | 重新获取该文件 |
| `无有效数据` | 格式对，但文件里解不出可用数据 | 换一个时次/文件，并反馈该文件 |

## 7. 常见使用套路

| 我想… | 这样做 |
|---|---|
| **同一时刻对比反射率和速度** | 点 `2屏`（或 4屏）→ 保持「多屏同步」勾选 → 分别点第 1、2 屏，在左侧各选一个产品 |
| **同一产品看不同时刻**（如 A 时 vs B 时） | 点 `2屏` → **取消「多屏同步」** → 分别激活两屏，在时间轴上各选各的时刻 |
| **看动画演变** | 单屏 + `▶ 播放`；想慢一点就先用刻度轴定位到起始时刻 |
| **只看 35~65 dBZ 的对流核心** | 图例上把左手柄拖到 35、右手柄拖到 65；其余强度全部透明，范围外查询仍会给数值并注明原因 |
| **把图例挪开挡住回波了** | 按住图例空白处拖到角落；看不见图例时（切了布局）它会自动回到画面内 |
| **查某个经纬度的具体数值** | 左下角坐标查询：填经度、纬度 → 回车；结果同时给「原始」与「9 点均值」 |
| **看雷达站在什么位置/某点离站多远** | 看查询结果里的 `azimuth/range`（弹窗显示经纬度）；或用底图注距估算 |
| **看高层结构** | 屏头仰角下拉换到更高仰角（如 3.5°、6.0°） |
| **比较平滑前后** | 用 2 屏，一屏勾「平滑」一屏不勾（每屏独立开关） |
| **临时看本机一份文件** | 屏头 `上传` → 选 `.bin`/`.m4`（也支持 `.bin.bz2`/`.m4.bz2`，≤200MB） |
| **看最新时次** | 时间轴拖到最右端；若右端不是最新 → 重新选「结束时间」锚点或刷新页面（Ctrl+F5） |

## 8. 快捷操作小抄

| 动作 | 效果 |
|---|---|
| 点任意一屏 | 该屏变激活屏（左上角 `●`） |
| 地图拖动 / 滚轮 | 平移 / 缩放；开「地图联动」时所有屏同步 |
| 点地图 | 弹窗显示该点数值 + 经纬度（无数据则静默关闭弹窗） |
| 刻度轴拖动 → 松手 | 吸附最近时次并加载 |
| 刻度轴滚轮 | 缩放时间窗 |
| 查询框回车 | 提交查询 |

| `重置` | 恢复全范围 |
| `Ctrl + F5` | 强制刷新，重新拉取产品目录/清单与最新时次 |

## 9. 常见问题（FAQ）

**Q1：页面是空白的 / 地图一直不出来？**
浏览器需支持 **WebGL2**（用较新的 Chrome 或 Edge）。若单位电脑确实只支持 WebGL1，可请管理员在
`src/main.ts` 里加一行 `consts.useWebGL2 = false` 降级（QuickEarth 会自动改走 WebGL1 着色器，
控制台会打印「当前WebGL使用版本：1」）。地图出来了但雷达层没有，先确认屏头状态文字（§6），而不是产品选错。

**Q2：回波一片都没有，但确定有降水？**
按顺序检查：① 屏头是不是「该时次无数据」；② 图例是不是被拖成了很窄的区间（点「重置」）；③ 反射率阈值 5 dBZ 以下的层状云弱回波本来就不上色（用坐标查询能看到 -5、3 dBZ 这类原始值）；④ 仰角层是不是切得太高，波束越过了云体（切回 0.5°）。

**Q3：切仰角后画面范围变小了？**
正常。高仰角层的探测距离设计值更小，且波束抬高后会被地形遮挡/越过降水。

**Q4：速度图上有大片空白 / 远处没颜色？**
正常。V/W 一般只在短距离圈采集（约 230km 内），且雷达质控会剔除低质量库。

**Q5：「原始值」和「9 点均值」该信哪个？**
判强中心用**原始值**（保峰值）；要看一片区域的平均强度、或和别的资料做定量对比用**均值**（会压低峰值）。速度场的均值是标量平均，跨越零速度线时会出现"伪小值"，仅供参考。

**Q6：底图切「行政」后是灰白一片？**
你的电脑访问不到瓦片服务。改回「国界」底图（本地数据，不依赖外部服务），或找管理员确认瓦片服务地址与网络。

**Q7：明明服务器上有新文件，页面上找不到？**
清单/时间轴是**打开页面时**读取的，平台不会自动轮询。请刷新页面（Ctrl+F5）；若仍无，说明清单还没包含该文件，联系管理员。

**Q8：时间跳转框选了时间却提示「该时次无数据」？**
跳转框是按分钟精确查找的，不做吸附。用底部刻度轴（拖拽松手会自动吸附到最近可用时次），或看刻度轴顶部绿色刻度对应的时间。

**Q9：同一个文件我刷新后画面没变？**
浏览器与平台都有缓存。用 `Ctrl + F5`；若是管理员替换了**同名文件**，则必须重开页面（平台内部按文件名缓存解析结果）。

**Q10：能导出图片 / 做动画文件吗？**
当前版本不提供导出功能，可在浏览器里对画面截图；需要批量出图请联系管理员（属平台外功能）。

**Q11：同一坐标查两次，换了文件（`.m4` / `.bin` / `.bin.bz2`）数值不一样？**
正常，**不是取值出错**。坐标查询的「来源」行已标明本次是哪种口径：

- `MICAPS m4` / `SWAN 拼图` 是**格点产品**：服务端做过多仰角合成、平滑插值，按最近格点取值（约 1km 量化），且**不提供 9 点均值**；
- `RSTM 基数据` 是**单站单仰角原始基数据**：按原始径向库取值（无格点量化），换仰角就是换高度，近距离速度梯度大，颜色跳档也属正常；
- `.bz2` 只是压缩包，与解压后的同名文件**数值完全一致**（若两者不同，几乎可以断定不是同一时次）。

比对前请统一三件事：**同一时次 + 同一仰角层 + 同一产品字段**。

## 10. 名词小词典

| 术语 | 通俗解释 |
|---|---|
| 反射率 Z / dBZ | 回波强度，数值越大降水越强（dBZ）。降水强度参考：20 弱、40 中、50+ 强 |
| dBT / dBZ | dBT 是原始反射率（含地物、噪声），dBZ 是滤波后的 |
| 径向速度 V | 目标沿雷达视线方向的速度分量，朝向/远离有正负之分（m/s） |
| 谱宽 W | 同一探测单元内速度差异大小，越大越乱流（m/s） |
| 双偏振量 | ZDR（形状）、CC（一致性）、KDP（强降水率）等双偏振雷达产品 |
| 体扫 | 雷达转一圈完成的一组仰角扫描（本平台数据常 5~6 分钟一次） |
| 仰角层 | 体扫里的每一圈对应一个俯仰角，低层看贴近地面、高层看高空 |
| 缺测 | 该处没有有效数据（图上透明） |
| 拼图 | 多台雷达合并成的区域格点产品 |
| 基数据 | 单台雷达的原始观测文件（本平台指 CINRAD 标准格式） |
| Nyquist（折叠速度） | 速度探测上限，超过会被"折叠"成假速度 |
| MICAPS m4 | 一种格点文本数据格式，平台可直接读 |

## 11. 使用时必须知道的四条口径

1. **「图上透明」≠「没有数据」**。查数请用左下角坐标查询，它会给出原始值并说明透明的原因。
2. **「示意数据」不是天气图**。出现该字样说明文件没能真实解码，画面是程序生成的演示团块，禁止用于任何业务判断，请立即反馈。
3. **平台显示的时间是北京时间**，与雷达数据文件的命名时间一致；数据到达有延迟，最新时次可能比当前钟表时间晚几分钟到十几分钟，这不代表平台故障。
4. **不同格式的同点数值本来就会不同**（格点产品 vs 单仰角基数据）。坐标查询的「来源」行会说明本次口径；跨文件比对请统一时次与仰角（见 Q11）。
