# 数据来源模式（dataSourceMode）说明

本文说明应用配置 `config.json` 中 `dataSourceMode` 字段的三种取值及其行为差异。
该字段控制平台从哪些来源获取雷达数据，**改配置即可生效，无需重新构建**（刷新页面后重新读取）。

---

## 1. 配置位置

字段位于应用配置文件 `config.json`（部署后通常为 `/data/config.json`）：

```json
{
  "dataSourceMode": "both",
  "fileUrlTemplate": "data/files/{time}.bin",
  "fileListUrl": "data/manifest.json",
  "timeline": {
    "mode": "obs",
    "intervalMinutes": 6,
    "lookbackDays": 10,
    "forecastHours": 24
  }
}
```

- 字段**可省略**：省略、拼错或取值非法时，一律按 `both` 处理。
- `config.json` 本身缺失或加载失败时同样回退 `both`（并回退为清单模式，时间轴取自清单时刻）。

---

## 2. 三种模式对照

| 项目 | `latest`（只通过最新数据接口） | `upload`（只通过上传文件） | `both`（同时存在，默认） |
| --- | --- | --- | --- |
| 服务器数据 | 只按「最新时间 + 模板地址」定位 | 不使用 | 使用（模板 / 清单） |
| 文件清单（manifest / 目录扫描） | 不加载 | 不加载 | 无 `fileUrlTemplate` 时加载 |
| 最新时间接口 | 查询，并跳转到最新时次 | **不查询** | 查询，并跳转到最新时次 |
| 时间轴 | 显示（按 `timeline` 配置生成） | **不显示** | 显示（按 `timeline` 配置生成） |
| 本地上传 | 保留 | 保留 | 保留 |
| 启动后初始画面 | 最新时次文件（存在则显示） | 空白，等待上传 | 最新时次文件（存在则显示） |
| 切换时次 | 按模板向服务器取数 | 清空为空白 | 按模板 / 清单取数 |

> 三种模式下上传入口（屏头「上传」、左侧「文件夹文件」）**始终保留**，不因模式隐藏。

---

## 3. 各模式详解

### 3.1 `latest` —— 只通过最新数据接口获取

适用场景：只需要展示**最新一帧**，不依赖文件清单 / 目录扫描。

行为：

1. 启动时调用「最新时间接口」获取最新时刻，吸附到时间轴上最近的时次并跳转；
2. 文件地址只由 `fileUrlTemplate` 按时刻构造，**不加载文件清单**；
3. 时间轴仍按 `timeline` 配置生成（可浏览历史时次）；
4. 上传入口保留，上传的数据可正常渲染、切产品 / 切仰角。

注意：

- **必须配置 `fileUrlTemplate`**。若未配置，控制台会输出告警，且各时次会显示「该时次无数据」。
- 其他历史时次是否可看，取决于「最新时间 + 模板地址」能否命中真实文件。

### 3.2 `upload` —— 只通过上传文件

适用场景：完全离线 / 无后端数据服务，只靠人工上传雷达文件。

行为：

1. **不查询最新时间**，不会自动跳转时次；
2. **不加载文件清单**，且**不向服务器请求任何雷达数据**；
3. **不显示时间轴**（底部没有时间轴区域，播放按钮同步隐藏）；
   文件通过左侧「文件夹文件」列表或屏头「上传」加载；
4. 启动后地图空白，等待用户上传；
5. 上传成功后，该文件作为**当前时次**的画面显示，可切产品 / 切仰角（局部刷新）。

注意：

- 「仅上传」模式没有时间轴 / 时次切换入口，上传的数据会一直保留到下一次上传或切换产品 / 仰角。
- `config.json` 仍建议保留：内部会依据 `timeline` 生成当前时次，用于绑定上传数据与屏头时间。

### 3.3 `both` —— 同时存在（默认）

适用场景：常规业务部署，服务器数据与人工上传都要用。

行为：

1. 时间轴按 `timeline` 配置生成；
2. 配置了 `fileUrlTemplate` → 按时刻构造文件地址；未配置 → 加载 `fileListUrl` 清单按时间匹配；
3. 启动时调用「最新时间接口」，跳转到最新时次；
4. 上传入口保留；
5. 上传的数据标记为当前时次，切产品 / 切仰角走局部刷新；**切时次后恢复服务器数据**（上传画面被替换）。

---

## 4. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `latest` 模式全屏「该时次无数据」 | 未配置 `fileUrlTemplate`，或模板地址与真实文件对不上 | 补全模板地址；确认 `{time}` 能被替换为 `yyyyMMddHHmmss` |
| `latest` / `both` 模式一直「加载中…」后失败 | 数据前缀 / 模板地址错误，请求返回 404 或 HTML 回落 | 核对 `VITE_DATA_BASE_URL` 与 nginx 数据 location 前缀是否逐字一致 |
| `upload` 模式看不到时间轴 / 播放按钮 | 该模式按设计隐藏时间轴与播放 | 切换为 `both` / `latest` 模式即可恢复 |
| 改了 `dataSourceMode` 没效果 | 页面未刷新，或改的不是实际生效的 `config.json` | 刷新页面；确认访问的是部署目录下的配置文件 |

---

## 5. 与 `fileUrlTemplate` / `fileListUrl` 的关系

| `dataSourceMode` | `fileUrlTemplate` 非空 | `fileUrlTemplate` 为空 |
| --- | --- | --- |
| `latest` | 按模板取数（推荐） | 不加载清单 → 无数据可显示（控制台告警） |
| `upload` | 不使用服务器数据 | 不使用服务器数据 |
| `both` | 按模板取数 | 加载 `fileListUrl` 清单按时间匹配 |
